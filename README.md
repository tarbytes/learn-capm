# CAPM 4-Week Learning Roadmap ✅

A focused, 4-week study plan to prepare for the **Certified Associate in Project Management (CAPM)** exam, based on the CAPM Exam Content Outline.

---

## Week 1 — Project Management Fundamentals & Core Concepts ✅

**Goals:**
- Understand **CAPM basics, exam format, and terminology**
- Learn **project life cycles, process groups, and stakeholder roles**

**Study Tasks:**
- [ ] Review CAPM Exam Content Outline and PMBOK® Guide sections
- [ ] Summarize core PM principles (inputs, tools, outputs)
- [ ] Create flashcards for key terms
- [ ] Map process groups to knowledge areas

---

## Week 2 — Predictive, Plan-Based Methodologies ✅

**Goals:**
- Master **traditional plan-driven PM approaches**
- Learn **integration, scope, schedule, cost, and quality management**

**Study Tasks:**
- [ ] Practice Work Breakdown Structures (WBS)
- [ ] Study Gantt charts and network diagrams
- [ ] Solve basic schedule and budget calculations
- [ ] Draft sample project planning documents

---

## Week 3 — Agile Frameworks & Business Analysis ✅

**Goals:**
- Understand **Agile principles, iterations, and artifacts**
- Learn **business analysis frameworks**: requirements, stakeholder engagement, traceability

**Study Tasks:**
- [ ] Compare predictive vs. Agile methodologies
- [ ] Study Agile ceremonies, roles, and backlogs
- [ ] Create sample requirement documents
- [ ] Practice stakeholder analysis

---

## Week 4 — Practice Exams & Final Review ✅

**Goals:**
- Consolidate all domains
- Build exam confidence

**Study Tasks:**
- [ ] Complete multiple **mock exams** covering all four domains
- [ ] Track weak areas and review concepts
- [ ] Revisit ITTOs (Inputs, Tools, Techniques, Outputs)
- [ ] Make a **final cheat sheet** for key terms and formulas
- [ ] Relax and mentally prepare for exam day

---

### Exam-Day Checklist ✅

- [ ] Sleep well and hydrate  
- [ ] Verify ID or online proctor setup  
- [ ] Bring approved materials (if applicable)  
- [ ] Manage time: ~3 hours for 150 questions  
- [ ] Mark tricky questions for review  
- [ ] Stay calm and focused
