# 📘 CAPM Week 1 Learning Plan — Domain 1: Fundamentals & Core Concepts

**Focus:** Project Management core principles — 36% of the CAPM exam.

---

## 📅 Day 1 — Introduction & Overview

### 🎯 Objective
- Understand CAPM exam structure (Domains, Tasks, Enablers)
- Recognize the importance of Domain 1

### 🧠 Topics
- CAPM domains and exam percentages
- Meaning of “fundamentals and core concepts” in PM

### 📚 Tasks
- Read the CAPM Exam Content Outline intro to Domain 1
- Create a one-page summary listing Domain 1 and its 5 tasks

---

## 📅 Day 2 — Task 1: Project Life Cycles & Key Distinctions

### 🎯 Objective
- Understand fundamental PM definitions and distinctions

### 🧠 Topics
- Project vs Program vs Portfolio
- Project vs Operations
- Predictive vs Adaptive approaches (Waterfall vs Agile)

### 📚 Activities
- Write definitions with real-world examples
- Create a comparison chart (time horizon, predictability, etc.)

### 📝 Mini-Assessment
- Write 2 short scenarios and identify if it’s a project, program, or operation

---

## 📅 Day 3 — Task 1 Continued: Risk & Scope Concepts

### 🎯 Objective
- Distinguish and interpret: Issues, Risks, Assumptions, Constraints, Project Scope

### 📚 Activities
- Define each term with a practical example
- Pick a simple project (e.g., event planning) and list:
  - potential risks
  - constraints
  - assumptions
  - issues

### 📝 Mini-Assessment
- Write 3 possible scope issues for your example project and how to address them

---

## 📅 Day 4 — Task 2: Project Management Planning Basics

### 🎯 Objective
- Understand why planning matters and key planning elements

### 🧠 Topics
- Cost, Quality, Schedule, Risk planning
- Project Management Plan vs Product Management Plan
- Milestones vs Task Duration

### 📚 Activities
- Sketch a simple project plan outline
- Create examples of milestones vs task durations

### 📝 Mini-Assessment
- List 3 milestones and task durations for a small project

---

## 📅 Day 5 — Planning Artifacts & Tools

### 🎯 Objective
- Understand and practice common planning tools

### 🧠 Topics
- Risk Register: purpose and usage
- Stakeholder Register: purpose and usage

### 📚 Activities
- Build a dummy risk register
- Build a stakeholder register with roles and engagement

### 📝 Mini-Assessment
- Explain in a paragraph how a risk register prevents surprises

---

## 📅 Day 6 — Task 3: Roles & Responsibilities

### 🎯 Objective
- Clarify roles in project environments

### 🧠 Topics
- Project Manager vs Sponsor vs Team
- Leadership vs Management
- Emotional Intelligence (EQ) in PM

### 📚 Activities
- Create a roles comparison table
- Reflect on how leadership and EQ help resolve conflicts

### 📝 Mini-Assessment
- Provide one example where EQ impacts team performance

---

## 📅 Day 7 — Tasks 4 & 5: Execution & Problem Solving

### 🎯 Objective
- Learn project execution and basic problem-solving techniques

### 🧠 Topics
- Project initiation and benefits planning
- Tailoring processes to context
- Problem-solving techniques (brainstorming, standups)

### 📚 Activities
- Create a mini project kickoff checklist
- Practice a brainstorming session on a mock problem

### 📝 Capstone Quiz
- Take a 20-question quiz covering all Day 1–Day 7 content

---

## 📌 Weekly Review & Reflection
- Rewrite Domain 1 summary in your own words
- Create 20 flashcards of key terms
- Take a Domain 1 mini mock exam
