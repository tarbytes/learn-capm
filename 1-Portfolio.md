# 📊 Project Management Hierarchy (Top-Down)

## Portfolio
- **Definition:** Collection of programs and projects aligned to strategic goals  
- **Example:** All IT initiatives in a company

## Program
- **Definition:** Group of related projects managed together for benefits  
- **Example:** Digital transformation program

## Project
- **Definition:** Temporary work to create a unique deliverable  
- **Example:** Build a company website

**Memory Tip:**  
- Portfolio → Strategy  
- Program → Benefits  
- Project → Deliverable
